# Atribuição e termos

O trabalho é uma reprodução de referência do VLTDet ([Hümmer et al., ACCV 2024; arXiv:2312.02021](https://arxiv.org/abs/2312.02021)), com a extensão para DINO com ResNet-50, mixture of experts por domínio e fine-tuning dos especialistas. A base de dados é a DWD (Diverse Weather Dataset). Consulte as páginas e os termos dos autores da base antes de usar, compartilhar ou redistribuir imagens, anotações ou resultados derivados.

- O código próprio deste repositório é disponibilizado sob MIT, conforme [`LICENSE`](../LICENSE).
- As figuras das galerias contêm trechos de cenas da DWD com caixas de anotação e predição sobrepostas. A licença MIT não se estende às fotografias nem às anotações.
- Os pesos do OpenCLIP (RN101), do ResNet-50 pré-treinado em ImageNet, o MMDetection/MMCV e as demais bibliotecas de terceiros seguem as próprias licenças e condições de acesso.
- Dados e pesos não são distribuídos com este repositório.
